# Changelog

## 1.0.0

- Custom resolution from 1024×768 up for the Russian GOG release of ROM.EXE.
- Right sidebar and spellbook bar adapted to screens taller and wider than 1024×768.
- Map rendered and clickable on both sides of the spellbook bar.
- Spell hotkeys F1–F8 (Ctrl+key to assign), kept across game restarts.
- Help, save and load moved to F9, F11 and F12.
- C casts the selected spell.
- cnc-ddraw 7.1.0.0 configuration for borderless fullscreen.
