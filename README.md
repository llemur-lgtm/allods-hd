# Allods HD

Неофициальный патч для **«Аллоды: Печать тайны»** (Rage of Mages, 1998), который делает игру
удобной на современных Windows и широких мониторах:

- игра идёт в любом разрешении от 1024×768 и выше, например 1600×900 или 1920×1080, на весь экран без
  чёрных полос;
- интерфейс подстроен под новый размер экрана;
- 8 горячих клавиш для заклинаний вместо 4, и они сохраняются между запусками игры;
- графика через [cnc-ddraw](https://github.com/FunkyFr3sh/cnc-ddraw): правильные цвета, без
  тормозов и мерцания на Windows 10/11.

[English version](README.en.md)

## Поддерживаемая версия игры

Сейчас поддерживается только **русская GOG-версия** («Аллоды: Печать тайны»). Патчер проверяет
`ROM.EXE` по контрольной сумме и откажется работать с другим файлом, поэтому повредить игру он
не может.

Другие издания (Steam, диск 1998 года, английская Rage of Mages) используют другой `ROM.EXE`.
Если у вас такая версия и вы готовы помочь с тестированием, создайте issue: поддержку
можно добавить, имея этот exe на руках.

## Установка

1. Скачайте архив со страницы [Releases](../../releases) и распакуйте его **в папку с игрой**
   (туда, где лежит `ROM.EXE`). Файлы `ddraw.dll` и `ddraw.ini` замените.
2. Запустите `allods-hd-patch.exe` и введите разрешение, например `1920x1080`, или просто
   нажмите Enter: тогда будет 1600×900.
3. Рядом с `ROM.EXE` появится `ROM_HD.EXE`. Играйте через него.

Исходный `ROM.EXE` не изменяется: через него игра запускается как раньше, но без доработок.

### Без exe-файла (через Python)

Нужен Python 3.8 или новее. Скопируйте в папку игры `game/ddraw.ini` и
`third_party/cnc-ddraw/ddraw.dll` из этого репозитория, затем выполните:

```
python patch.py 1920 1080 --game-dir "путь\к\игре"
```

## Как выбрать разрешение

Чем больше разрешение, тем больше карты видно и тем мельче персонажи. Удобнее всего брать
разрешение с тем же соотношением сторон, что у монитора, и примерно в 1,5–2 раза меньше
по каждой стороне:

| Монитор | Разрешение для патча |
|---|---|
| 2560×1440 | 1600×900 |
| 1920×1080 | 1366×768 |
| 3440×1440 | 2148×900 |

Высота должна быть не меньше 768, ширина не меньше 1024 и кратна 4.

Разрешение можно поменять в любой момент, просто запустив патчер ещё раз.

## Что меняется в игре

### Интерфейс

- Правая панель: характеристики персонажа прижаты к низу экрана, а свободное место над ними
  заполнено орнаментом.
- Полоса книги заклинаний шириной ровно в ячейки. Слева и справа от неё видна карта, и по ней
  можно кликать.
- Инвентарь растягивается на всю ширину (так игра умеет сама).

### Клавиши

| Клавиша | В оригинале | С патчем |
|---|---|---|
| F1–F4 | справка, сохранение, загрузка, — | заклинания 5–8 |
| F5–F8 | заклинания 1–4 | заклинания 1–4 |
| Ctrl + F1…F8 | — / назначить заклинание | назначить заклинание на клавишу |
| F9 | — | справка (список клавиш) |
| F11 | — | сохранить игру |
| F12 | отладочный счётчик кадров | загрузить игру |
| C | открыть книгу для выбора заклинания | применить выбранное заклинание; если ничего не выбрано — открыть книгу |

F10 не используется: в Windows это системная клавиша.

Чтобы назначить заклинание, откройте книгу (Q или B), выберите заклинание или наведите на него
курсор и нажмите Ctrl + F-клавишу. На значке появится подпись, например «F1».

Назначения хранятся в реестре: `HKEY_CURRENT_USER\Software\1C\Allods HD`, значение
`SpellHotkeys`. Они общие для всех сохранений.

Остальные клавиши не изменились, их список открывается по F9.

## Удаление

Удалите `ROM_HD.EXE`. Чтобы вернуть и графику как было, удалите `ddraw.dll` и `ddraw.ini`
(или верните свои старые версии). Назначения горячих клавиш удаляются вместе с разделом реестра
`HKEY_CURRENT_USER\Software\1C\Allods HD`.

## Известные ограничения

- Встроенная справка игры по-прежнему называет F1, F2 и F3 клавишами справки, сохранения и
  загрузки.
- Патч проверен в разрешении 1600×900: карта, правая панель, книга заклинаний, инвентарь,
  горячие клавиши, сохранение и загрузка. Если где-то интерфейс выглядит неправильно, создайте
  issue со скриншотом и укажите разрешение.

## Как это работает

`patch.py` берёт `ROM.EXE`, вносит изменения в машинный код и сохраняет результат как
`ROM_HD.EXE`. Файлов игры в репозитории нет: только адреса правок и новый код. Подробности для
разработчиков — в [docs/TECHNICAL.md](docs/TECHNICAL.md).

### Сборка exe

```
pip install -r requirements-build.txt
python build.py
```

Готовый архив для релиза появится в папке `release/`.
